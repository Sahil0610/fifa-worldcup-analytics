# FIFA World Cup Analytics Project

## Overview
End-to-end data analytics project using FIFA World Cup historical data.

## Tech Stack
- Python (Pandas, NumPy)
- SQL Server
- Power BI
- ETL pipeline

## Workflow
Raw Data → Cleaning → Feature Engineering → SQL Database → Power BI Dashboard

## Features
- Goal analysis
- Team performance ranking
- Attendance trends
- Match outcome classification
- Knockout vs group stage analysis

Work in progress (Step-by-step build)
